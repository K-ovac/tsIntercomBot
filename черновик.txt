так, хорошо. давай сейчас поработаем над файлом запуска и настройкой кнопок. у меня есть вот такой файл с кнопками. не знаю, нужен ли он. ну вообще нужен. крч. как реализовать вообще файл запуска? вот критерии:
1. будет учет юзеров. юзеры в файле users.json в формате
{
  "admins": ["12345", "67890"],
  "users": {
      "peer_id": "11223",
      "name": "Имя",
      "services": ["intercoms", "camers", "barriers"]
  },
}
для admins будут доступны как админские команды, так и обычные для юзеров. а для users - обычные команды, но есть кнопки, которые должны отображаться только, если они добавлены для использования.
для админов будут реализованы команды добавления и удаления юзеров, добавления, удаления и редактирования панелей. для них кнопки не будут предназначены. только сами команды.
суть работы домофона:
токен бота и чат айди для отправки логов назодятся в файле config.json. формат такой:
{
  "bot_token": "token",
  "chat_id": "id",
  "logging_level": "DEBUG"
}

1. после старта проверяется, есть ли юзер в списке, при отсутствии пишет сообщение "доступ закрыт. для доступа обратитесь к @biu_jays. Ваш ID: peer_id". Если юзер есть, значит вывести сообщение для выбора услуги и кнопки с services, доступные для юзера, то есть показывать кнопки Домофоны/Камеры/Шлагбаумы или вместе. Они отмечены под ключом services.
если это админ, значит показывать все.
2. юзер выбирает сервис, далее бот просит указать адрес для поиска, искать должен только по значению ключа из panels.json. то есть находить по части слова или полному.
3. бот выводит кнопки и список найденных панелей. выбирает нужную и выводится список кнопок с действиями. мы уже как-то делали файл с кнопками - buttons.py. может пригодится, вот он:
